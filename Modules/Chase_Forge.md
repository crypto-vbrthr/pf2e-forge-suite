# Chase Forge

**Chase Forge** is a comprehensive chase framework for Pathfinder 2E in Foundry VTT, designed to help Game Masters prepare, generate, run, and manage dynamic pursuits using PF2e's chase rules.

The visual **Chase Builder** allows Game Masters to create linear or branching routes from reusable obstacle cards, define multiple approaches for each challenge, assign participants, configure endings, and add consequences. Prepared chases can be saved for later use, linked from Foundry Journals, or supplied by optional add-on libraries without modifying their original content.

Chases can also be generated from configurable templates. Chase Forge includes a built-in **72-card Core Library** covering environments such as **cities, wilderness, dungeons, coasts, mountains, and social situations**, together with templates for **classic pursuits, branching pursuits, escapes, races, and against-the-clock scenarios**. Seeded generation makes results reproducible, while generated cards remain fully editable.

During play, the dedicated **GM Runner** manages the active chase, Chase Points, approaches, rolls, route progression, consequences, rounds, and endings. A synchronized **Player View** shows each player only the information currently relevant to their character, while hidden DCs, GM notes, undiscovered routes, and future obstacles remain private.

Chase Forge supports several styles of PF2e chase, including **pursuits, escapes, races, and time-limited challenges**. Approaches can use skills, Perception, saving throws, or attacks, with support for simple DCs, level-based DCs, proficiency requirements, difficulty adjustments, and PF2e degree-of-success handling.

Advanced routing allows a party to **split into separate groups, take different branches, progress independently, transfer participants, and merge again later**. Pursuers and quarries can therefore become scattered across a route instead of being treated as permanently synchronized blocks. The GM Runner provides a route monitor and assistance with group ordering, while split quarry groups can even resolve with different outcomes.

Cards can contain mechanical consequences triggered by their outcomes. Optional integration with **Critical Forge / Effect Forge** allows those consequences to use reusable Effect Forge definitions and be applied directly from the GM Runner, through confirmation dialogs or chat cards, or automatically according to the Game Master's preferred workflow.

Chase Forge also supports optional integration with other Forge modules. **Campaign Forge** can reference and launch prepared chases while receiving their final results, **Weather Forge** can provide current environmental context, and the public extension API allows add-ons to contribute **cards, templates, complete prepared chases, and image providers**.

A shared visual system supports manual artwork, predefined card images, and optional image providers, while import/export and protected persistence make prepared chases portable and safe across Foundry sessions.

All integrations are optional, and Chase Forge remains fully usable as a standalone chase-management module.

Chase Forge is available in **English and German**.

**Requires Foundry VTT 14 and Pathfinder 2E 8.1.2 or later.**

The **Chase Forge** can be found here: https://github.com/crypto-vbrthr/pf2e-chase-forge

**Chase Forge is available on Foundry VTT's module repository.**
