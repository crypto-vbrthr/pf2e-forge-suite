## Calendar Forge: Golarion

**Calendar Forge: Golarion** is the Golarion setting content package for **Calendar Forge**, providing the calendar, seasonal, lunar, regional, astronomical, and historical context needed to use Calendar Forge with Pathfinder 2E's default campaign world.

The add-on provides the **Absalom Reckoning calendar**, including Golarion's canonical **month and weekday names**, together with optional alternate names that make their real-world equivalents easier to recognize at a glance. Calendar Forge can therefore display setting-appropriate dates while still remaining convenient to use during play.

Beyond the calendar itself, the package supplies dedicated **season profiles, regional contexts, moon data, holidays, astronomical events, and historical timeline entries**. These definitions allow Calendar Forge to present the current date as part of Golarion rather than merely converting Foundry world time into generic months and days.

The provided regional and seasonal information also gives other Forge modules a common temporal context. **Weather Forge**, for example, can combine the current Golarion date and season from Calendar Forge with location and climate information from City Forge when generating weather.

Calendar Forge: Golarion can synchronize its interpretation of time with the existing **PF2e system clock** without replacing Foundry's `game.time.worldTime`. The module therefore does not introduce a competing clock. It provides the setting-specific interpretation of the same authoritative world time used by Foundry and the PF2e system. Lunar calculations are likewise anchored to in-world calendar dates so moon phases remain aligned with the intended Golarion chronology.

The package is implemented entirely through Calendar Forge's **Content Provider system**. Its setting data remains separate from Calendar Forge core, preserving the core module's system- and setting-independent design. Provider content carries source and version information, and Game Masters may duplicate definitions into editable world data when campaign-specific changes are desired.

Calendar Forge: Golarion also provides a coherent set of **suggested defaults** for the Golarion calendar, Inner Sea regional context, seasonal profile, and moon. These defaults are never forced onto an existing campaign and are only applied when the Game Master explicitly chooses to use them.

All setting content is available in **English and German**.

**Requires Calendar Forge.**
