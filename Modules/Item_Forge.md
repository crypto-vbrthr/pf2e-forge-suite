# Item Forge

**Item Forge** is a reusable item-generation engine for Pathfinder 2E in Foundry VTT, designed to create, select, and compose **level-appropriate equipment, magic items, valuables, and other inventory objects** while preserving PF2e's native item structures wherever possible.

Game Masters can generate items by **category, level or level range, source, theme, and generation policy**. Item Forge can select existing equipment directly from configured compendia or construct new items using reviewed generation profiles. Supported categories include ordinary **weapons, armor, shields, scrolls, and equipment**, as well as specialized magic items such as **wands, staves, spellhearts, grimoires, apex items, worn and held magic items, specific magic weapons and armor, specific shields, and accessory runes**.

Generated equipment can incorporate appropriate **fundamental and property runes**, while spell-bearing items use actual spells from the selected PF2e sources and respect valid spell ranks and meaningful heightening. More complex magic items use coherent profiles rather than assembling unrelated effects at random, helping generated results remain thematically and mechanically consistent.

Item Forge also contains an extensive **treasure generator** capable of creating individual valuables from dozens of treasure types, materials, motifs, conditions, craftsmanship levels, styles, and reusable components. Generated treasures include detailed descriptions and transparent valuation metadata, allowing them to function as believable objects rather than anonymous amounts of gold.

A configurable **Compendium Source Policy** lets the Game Master decide which PF2e system or additional content sources may contribute published items, spells, equipment, and other generation components. Existing PF2e items are preserved with their native rules and automation, while generated content clearly distinguishes native automation from abilities represented through structured metadata and readable rules text.

The integrated **Item Forge Editor** provides generation controls, previews, rerolls, source selection, and item descriptions before anything is created in the world. Deterministic seeded generation also makes results reproducible when needed.

Item Forge exposes a stable **public API and extension registries**, allowing other Forge modules and add-ons to use the same generation engine, add new item categories, profiles, and generators, or request items without duplicating the underlying logic.

Item Forge is available in **English and German**.

The **Item Forge** can be found here: https://github.com/crypto-vbrthr/pf2e-item-forge

**Item Forge is available on Foundry VTT's module repository.**
